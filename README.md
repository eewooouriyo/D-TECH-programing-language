## 🤝 How to Contribute

I'm actively looking for help! There are several ways you can contribute:

### 1. 💻 Help with the Interpreter
The D-TECH interpreter is still under development. If you're interested in:
- Building the interpreter core
- Implementing language features
- Optimizing performance
- Writing tests
- Bug fixing and debugging

**Please reach out or open an issue!**

### 2. 📦 Create Imports/Libraries
D-TECH needs a robust ecosystem of libraries and imports. You can help by:
- Creating utility libraries
- Building standard library modules
- Developing frameworks
- Contributing to the first import library (currently in progress)
